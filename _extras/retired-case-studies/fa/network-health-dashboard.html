فعال ابزارهای داخلی

داشبورد سلامت شبکه

یک ابزار داخلی برای یک ارائه‌دهنده کوچک اینترنت که زمان فعالیت، تأخیر، و حجم تکت‌ها را در یک صفحه نمایش می‌دهد.

JavaScript رسم نمودار REST API

چالش

کارمندان یک ارائه‌دهنده کوچک اینترنت هر صبح سه صفحه‌گسترده جداگانه را بررسی می‌کردند — یکی برای زمان فعالیت، یکی برای لاگ‌های تأخیر، یکی برای تکت‌های باز پشتیبانی — تا تصویری از سلامت شبکه به‌دست آورند. مشکلی در داده‌ها نبود؛ فقط در یک‌جا نبودند.

رویکرد

یک داشبورد واحد ساختم که از منابع داده موجود از طریق APIهای آن‌ها می‌کشد و زمان فعالیت، روند تأخیر، و حجم تکت را با هم نمایش می‌دهد، هر چند دقیقه یک‌بار به‌روزرسانی می‌شود بدون نیاز به مرحله خروجی دستی.

نتیجه

روال صبحگاهی بررسی سه صفحه‌گسترده با یک صفحه جایگزین شد. کارمندان زودتر متوجه ناهنجاری‌ها می‌شوند، چون ارتباط بین افزایش تأخیر و تکت‌های ورودی اکنون در یک نگاه قابل مشاهده است، نه اینکه کسی به‌صورت دستی آن‌ها را مقایسه کند.

ساخته‌شده با

JavaScript (ES6+)
یکپارچه‌سازی REST API
رسم نمودار
نظرسنجی زمان‌بندی‌شده
